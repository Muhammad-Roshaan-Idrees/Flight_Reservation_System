# Flight Reservation System (C++)
Console-based airline booking, seat management, and passenger ticketing system.

## Version 2.0 Roadmap
- Multi-leg flight support
- Seat map visualization
- Automated ticket export

## Baggage Policy
- Economy: 20kg checked
- Business: 35kg checked

## Ticket Receipts
Confirmed bookings automatically generate a printable .txt boarding pass.

## Troubleshooting
Ensure data files remain in the root working directory during execution.
