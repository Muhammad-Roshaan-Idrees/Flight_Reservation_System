# Flight_Reservation_System

This project is a Flight Reservation System developed as part of my 3rd semester coursework for Data Structures and Algorithms. The system uses key data structures like queues and hash maps to manage bookings, making it efficient and scalable for processing multiple reservations.

*Features:*
Here are some of the key features that our program is going to have and be implemeneted on using data structures.

   *Flight Booking:* Reserve flights with ease, adding passengers to a queue for each flight.
  
  *Reservation Management:* Store and retrieve reservations quickly using hash maps.
  
  *Waitlist System:* Utilize queues to manage waitlists for fully booked flights.
  
  *Data Validation:* Verify and organize input data for secure processing.
  
  *Flight Lookup:* Quickly access information on flights using hashed indices for efficient data retrieval.

*Data Structures Used*

These are the data structures that we are currently using in our project with C++.

  *Queues:* Queues manage the sequential order of passenger reservations and handle waitlists for each flight, ensuring that reservations follow a first-come, first-served process.
  
  *Hash Maps:* Hash maps are employed to store flight information and passenger data, allowing for fast lookups and improved access times
